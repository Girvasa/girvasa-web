# girvasa-web

Web administration portal and marketing website for **Girvasa (Society OS)** (Next.js 14 App Router + TypeScript + Tailwind CSS).

- Vector & PNG masters: `public/brand/girvasa-logo.svg`, `public/brand/girvasa-logo-white.svg`, `public/brand/girvasa-logo.png`, `public/brand/girvasa-logo-email.png`
- Browser, Apple, PWA & Social metadata: `public/favicon.ico`, `src/app/icon.svg`, `src/app/apple-icon.png`, `src/app/manifest.ts`, `src/app/opengraph-image.png`, `src/app/twitter-image.png`
- Web Push notification icons: `public/icons/notification-icon-192.png`, `public/icons/notification-badge-96.png` (`public/firebase-messaging-sw.js`)
- Reusable UI emblem component: `src/components/common/GirvasaLogo.tsx`
